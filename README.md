## 🌟 プロジェクト概要

**Zenislate**（ゼニスレート）は、余剰になったPC、遊休スマートフォン、タブレット、モニター、スマートテレビ（Android TV / Fire OS）のWebブラウザまたはネイティブアプリ上で常時稼働し、Amazon Echo ShowやGoogle Nest Hub同等以上の体験を提供する、完全オープンソースの万能アンビエント・スマートディスプレイです。

- **プライバシー保護**: すべてのデータ・設定・メモは端末内部（IndexedDB / localStorage）に安全に保持されます。
- **有料契約・APIキー不要**: 気象情報、ニュース、ネットラジオ、音響合成まですべて無料・公開プロトコルで自律稼働します。
- **マルチランタイム単一コードベース**: 共通のReact + TypeScriptフロントエンドから、**Web静的配信＋マルチCGI**、**Android (スマホ/タブレット/TV)**、**Windowsデスクトップ** の3系統に展開可能です。

## ⏰ 通常アラーム & 特殊アラーム6種ミッション

アラーム鳴動時、二度寝を防止するため、指定したミッションを完全にクリアするまで音が停止しない強力な解除システムを内蔵しています。

1. **計算ミッション (`math`)**: 3段階難易度（初級・中級・上級）の暗算を解くまで停止不可。TVリモコン十字キーで操作可能なオンスクリーンテンキー付き。
2. **朝の音声ブリーフィング (`briefing`)**: Web Speech APIにより、現在時刻・日付・祝日・設定都市の朝の挨拶を自動読み上げ完了で停止。
3. **サンライズ調光 (`sunrise`)**: アラーム時刻の5分前から全画面が朝焼け色に徐々に発光し、自然な目覚めを促す光目覚まし。
4. **シェイク・連打ミッション (`shake`)**: スマートフォンを激しく振るか、円形ボタンを規定回数（30回）タップするまで停止不可。
5. **サイモン記憶ゲーム (`simon`)**: 4色の光と和音の点滅シーケンスを記憶して正しくリピート入力することで停止。
6. **QRコードスキャン (`qr`)**: 洗面所や台所に貼ったQRコードをカメラで読み取って停止（カメラ非搭載端末では自動的に緊急計算ミッションへ安全フォールバック）。

## 🎵 プロシージャル音響エンジン & ネットラジオ

外部の重いMP3ファイルをダウンロードすることなく、端末のWeb Audio APIによる数学的波形合成で音響を再生します。通信量0KB、完全オフラインで動作します。

- **和音チャイム**: ペンタトニック音階（C4, E4, G4, B4, D5）による心地よい目覚ましチャイム。
- **プロシージャル雨音**: ピンクノイズとバンドパスフィルターによる優しい雨粒のシミュレーション。
- **寄せる波の音**: ブラウンノイズと低周波LFOフィルター周期変調による打ち寄せる波の再現。
- **焚き火の温もり**: フィルター変調によるランダムなパチパチ音と温かいパルス。
- **静寂ホワイトノイズ**: 集中・睡眠導入のための均一なホワイトノイズ。
- **Radio-Browser ネットラジオ**: 世界各国のコミュニティFM、Lofi Cafe、クラシックピアノ、ジャズストリームの直接再生。

## 📅 日本祝日完全計算エンジン (`JapaneseHolidays.ts`)

外部祝日APIの障害やサービス終了に影響されないよう、純粋な暦学・天文学計算アルゴリズムを内蔵しています。
- 春分の日・秋の日の天文計算式対応（1900年〜2099年完全対応）
- 成人の日・海の日・敬老の日・スポーツの日のハッピーマンデー（第N月曜日）算出
- 祝日が日曜日と重複した場合の翌月曜以降への「振替休日」算出
- 祝日に挟まれた平日を休日にする「国民の休日」（シルバーウィーク等）算出

## 🎮 Android TV リモコン空間ナビゲーション（D-Pad）

Android TVやFire OSのリモコン十字キー（↑↓←→）および決定キー（Enter）による直感的なフォーカス移動をピュアTypeScriptで実装しています。
- 各操作可能要素（`[data-focusable="true"]`）の幾何学的中心座標をリアルタイム計算し、入力方向にある最も近い要素へ自然にフォーカスを誘導します。
- フォーカスされた要素にはTV向けのアウトラインリング（シアンブルーのグロー効果）が明瞭に表示されます。

## 🚀 ビルド & 展開手順

### 1. Web静的ホスティング & マルチCGIプロキシ

Apache、Nginx、レンタルサーバー（さくら、XREA等）に配置する場合：

```bash
# ビルドの実行
npm run build
```

- 出力された `dist/` ディレクトリ配下の全静的ファイルをサーバーの公開ルートへアップロードします。
- CORSエラーを回避してRSSニュースを取得したい場合、サーバー環境に合わせて `backend/` ディレクトリのスクリプトを設置してください：
  - PHPサーバー: `backend/news.php`
  - Python CGIサーバー: `backend/news.py` (パーミッション `755`)
  - Perl CGIサーバー: `backend/news.cgi` (パーミッション `755`)
  - Ruby CGIサーバー: `backend/news.rb` (パーミッション `755`)

### 2. Android / Android TV アプリ (Capacitor)

```bash
# WebアセットのビルドとAndroid同期
npm run build
npx cap sync android

# Android Studioでの起動またはAPKビルド
npx cap open android
```
- `android/app/src/main/AndroidManifest.xml` にて `android.software.leanback` および `android.hardware.touchscreen=false` が定義されているため、同一のAPKでスマートフォン、タブレット、Android TVのすべての端末に対応します。

### 3. Windows 11 デスクトップアプリ (Tauri v2)

```bash
# 開発時プレビュー
npm run tauri dev

# リリースインストーラー (.exe / .msi) のビルド
npm run tauri build
```
- WebView2ランタイムを活用した軽量設計（起動時メモリ50MB以下）。
- タスクトレイ格納機能およびPC起動時の自動起動（Autostart）プラグインが組み込まれています。
